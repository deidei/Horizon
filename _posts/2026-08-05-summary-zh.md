## [杰夫·迪恩创办 Discovery Loop，自动化科学实验循环](https://www.discoveryloop.com/) ⭐️ 9.0/10

杰夫·迪恩（Jeff Dean）与多位谷歌高级 AI 负责人共同创办了 Discovery Loop，这是一家旨在自动化科学与工程领域实验循环的初创公司，初期聚焦于机器学习研究与工程。该项目利用大规模系统，让 AI 代理能够大规模地提出、运行和分析实验。 如果成功，这可能代表 AI 驱动发现的范式转变，大幅加速药物研发、芯片设计等领域的进展。这也表明谷歌顶尖 AI 人才将自主实验视为下一个重大研究前沿。 该方法的重点是自动化实验循环，创始团队表示它有助于解决美国国家工程院（NAE）十四大挑战问题中的几乎所有子问题。要做好这一点，需要在机器学习和大型系统方面都具备深厚专业能力；这家初创公司初期聚焦于 ML 研究与工程。

## [ChainDrop 蠕虫攻陷 npm 逾 1,300 个包](https://www.bleepingcomputer.com/news/security/massive-chaindrop-npm-supply-chain-attack-infects-hundreds-of-packages/) ⭐️ 9.0/10

自我传播的 ChainDrop 蠕虫已攻陷超过 1,300 个 npm 包，包括流行的 Keyv 和 Cacheable 缓存库，这些库每月合计下载量约 20 亿次。攻击始于被劫持的 Keyv 维护者账号，并于 2026 年 8 月 4 日通过带有合法来源证明的 GitHub Actions 工作流发布恶意版本进行扩散。 这是迄今为止规模最大的 npm 供应链攻击之一，波及每月下载量达数十亿次的软件包，并可能泄露无数开发环境中的 GitHub、npm、AWS 和 Kubernetes 凭证。使用受影响软件包的组织必须将其系统视为已被攻破，立即轮换所有密钥并审计日志。 恶意载荷包含 setup.mjs 投放器和 Math_Symbol.js 凭证窃取脚本，会在执行 npm install 时自动运行，窃取 GitHub、npm、AWS 和 Kubernetes 凭证。Microsoft 和 stepsecurity 的研究人员报告称，该蠕虫通过重新发布恶意更新来感染其他维护者的包；域名 npm-cache[.]com 可作为失陷指标，且攻击仍在持续。

telegram · zaihuapd · 8月5日 03:04

**背景**: npm 是 Node.js 的默认软件包仓库，供应链攻击通过向已发布的包中注入恶意代码，使安装它们的开发者在不知情的情况下执行载荷。在自我传播蠕虫攻击中，恶意软件利用窃取的凭证发布其他包的恶意版本，从而在无需攻击者直接介入的情况下扩大影响范围。ChainDrop 的特别之处在于利用 GitHub Actions 并带有合法来源证明，这使得恶意版本看起来值得信赖，绕过了常见的信任检查。

## [FFmpeg 9.0 发布：新增动画 WebP 与 AI 辅助开发](https://news.ycombinator.com/item?id=49166202) ⭐️ 9.0/10

FFmpeg 9.0 已正式发布。它新增了动画 WebP 解码器与分离器、v360_vulkan 滤镜、Playdate 视频编码器及封装器、HE-AAC 960 解码、transpose_cuda 滤镜、AMF 帧率转换器滤镜，以及 ONNX Runtime DNN 后端。 作为使用最广泛的开源多媒体框架之一，这一大版本发布为视频编码、处理和基于 AI 的滤镜带来了重要的新能力。同时，这也是 FFmpeg 项目在 AI 辅助开发方面迈出的引人注目的一步，引发了对审查与安全流程的讨论。 通过 Anthropic 的 Claude for Open Source Program，FFmpeg 团队获得了六个月的免费 Claude Max 使用权，主要利用 AI 来查找缺失的向后移植。ONNX Runtime 后端由 AMD 工程师 Steven Xiao 贡献，扩展了 FFmpeg DNN 滤镜对 GPU 和 NPU 的支持。

**背景**: FFmpeg 是处理多媒体数据的领先开源套件，广泛应用于视频播放器、转码器和流媒体服务。9.0 是一个重要里程碑，带来了新的编解码器、滤镜和基于机器学习的处理后端。v360_vulkan 滤镜支持 GPU 加速的 360 度视频转换，而 ONNX Runtime 后端允许在 FFmpeg 管线中运行 AI 模型。动画 WebP 支持则扩展了该框架对静态图像和短动画的处理能力。

## [DeepSeek 重启第二轮融资，投前估值 5000 亿元](https://finance.sina.com.cn/wm/2026-08-05/doc-inimfmyv1554159.shtml) ⭐️ 8.0/10

DeepSeek 已重启第二轮融资，计划募资 500 亿元，投前估值约 5000 亿元，较首轮提升 43%。预计 8 月下旬完成签约。 这笔大规模融资凸显了 DeepSeek 的快速成长以及中国 AI 行业对资本的强烈需求。估值提升 43%表明投资者信心强劲，若顺利完成，两轮募资合计将超过 1000 亿元，将重塑大模型市场的竞争格局。 本轮融资于 7 月中旬启动，但在 7 月底突然暂停，据称是因为创始人梁文锋对网上流传的疑似投资者会议实录泄露内容不满。部分此前积极接触的机构表示尚未接到重启消息，预计本轮将低调进行。
